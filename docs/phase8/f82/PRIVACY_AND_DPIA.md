# Privacy and DPIA Notes

- Records are organisation-scoped with RLS.
- Audit events avoid unnecessary personal data in metadata.
- Retention configurable per organisation (`retention_days`); legal/safeguarding holds take precedence.
- AI assist uses existing authorised data only; metering feature id `ai.addon.safeguarding_alerts`.
- Production activation requires privacy review flag and DPIA sign-off per F7.2 process.
