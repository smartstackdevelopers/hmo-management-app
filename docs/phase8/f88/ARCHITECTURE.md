# F8.8 Gamification Architecture

Optional add-on for goals, milestones, badges, optional points, activities, timeline, and opt-in leaderboard. Complements (does not replace) support plans, career goals, or LMS.

API: `/api/v1/tenant-engagement`

Gate: `TENANT_ENGAGEMENT_GLOBAL_ENABLED=false`

Points never affect housing eligibility or essential services.
