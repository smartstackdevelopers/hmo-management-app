# F6.5 Room Occupancy Module

Privacy-gated estimated people counting. **Live camera/RTSP activation remains disabled until the organisation privacy approval gate is complete and live counting is explicitly enabled.** HMore never auto-approves DPIA or feasibility.

## Privacy rules

- No facial recognition, identity tracking, or biometrics
- No cameras in bedrooms, bathrooms, or changing rooms
- Edge/device counting preferred; store estimated counts only
- No raw video storage by default
- Offline rooms never display as zero occupants

## Approval gate

Statuses (`not_started` → `approved`): feasibility, DPIA, signage, retention policy, camera compatibility. Also requires approved room purposes, authorised viewer notes, accuracy notes, and a formal approval stamp.

## Permissions

- `occupancy.read` — view counts (org admin, support worker, super admin)
- `occupancy.settings.manage` — gate, devices, thresholds
- `occupancy.counts.correct` — manual corrections
- `occupancy.alerts.manage` — acknowledge alerts  
Landlord and tenant: no live occupancy by default.

## API

Prefix: `/api/v1/room-occupancy`

- `GET /dashboard`, `GET|PATCH /approval-gate`, `GET|PATCH /settings`
- `GET|POST /devices`, `PATCH /devices/{id}`
- `GET /rooms`, `POST /counts/ingest`, `POST /rooms/{id}/correct`
- `GET /history`, `GET /reports/usage`, `GET /alerts`, `GET /corrections`
