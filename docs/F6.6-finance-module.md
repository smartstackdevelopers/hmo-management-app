# F6.6 Optional Finance Module

## Status: **Selected – Client Approved (chat approval 2026-11-12)**

Finance & Budgets Section 11 add-on authorised for build. **Payment gateways, banking connections, and automatic money transfers remain out of scope** unless separately approved.

## Scope delivered

- Finance dashboard (income/expense posted totals, rent outstanding from F6.1 ledger)
- Financial record CRUD (draft/posted/void) with history + audit
- Optional link to existing `rent_records` (no duplicated rent ledger)
- Budgets, budget lines, budget vs actual variance
- CSV / PDF / Excel exports via F6.2 export helpers
- Org isolation + RBAC (`finance.*` permissions)

## Explicitly not included

- Online payment collection
- Payment gateways / banking APIs
- Automatic money transfers
- Claiming bank-verified receipt without a verified ledger/rent record

## Permissions

- `finance.records.read` / `finance.records.manage`
- `finance.budgets.read` / `finance.budgets.manage`
- `finance.reports.view` / `finance.exports`

Org Admin + Super Admin: full. Landlord: read/reports. Tenant/Support Worker: no manage.

## API

Prefix: `/api/v1/finance`

- `GET /dashboard`, `GET /categories`
- `GET|POST /records`, `PATCH /records/{id}`, `POST /records/{id}/void`
- `GET|POST /budgets`, `PATCH /budgets/{id}/status`, `GET /budgets/{id}/variance`
- `GET /exports/records?export_format=csv|pdf|xlsx`
