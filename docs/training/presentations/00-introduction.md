# HMore introduction

## What is HMore?
- Housing + support platform for organisations
- Web dashboard + mobile app
- Role-based access (six roles)

## Who uses it?
- Super Admin, Organisation Admin, Landlord
- Tenant, Support Worker, Maintenance contractor

## Principles
- One backend (FastAPI)
- Auth0 login, MFA for staff
- AI assists — humans decide
