# QR: Create a tenant record

**Role:** Organisation Admin (typically).

1. Sign in → **Tenants** (nav).
2. **New tenant** — complete required fields (no real PII in training).
3. Assign property/room if applicable.
4. Invite tenant user (Auth0) when ready.
5. Confirm tenant sees only own data on mobile login.

**Mistake:** Duplicate records — use duplicate detection dashboard if enabled.
