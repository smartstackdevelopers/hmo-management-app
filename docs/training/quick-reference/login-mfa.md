# QR: Login & MFA

1. Open organisation URL or HMore app.
2. Enter email + password (Auth0).
3. Complete MFA code if prompted.
4. If failed: check caps lock; use **Forgot password** on Auth0 screen.
5. Staff: never approve MFA push you did not start.

**Web sign out:** Dashboard header → Log out. **Mobile:** More → sign out / security.
