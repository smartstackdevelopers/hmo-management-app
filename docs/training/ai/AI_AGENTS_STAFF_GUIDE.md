# AI agents — staff training guide

HMore includes **six AI-assisted workflows** (Phase 3+). AI is **advisory**; humans remain accountable.

| Agent | Purpose | Human approval |
| --- | --- | --- |
| Notes Analysis | Summarise daily notes | Review before sharing externally |
| Support Planning | Draft support plans | **Required** before apply to record |
| Housing Application | Analyse application packs | **Staff/org decide** — no auto approve/reject |
| Compliance | Compliance checks assistance | Officer confirms |
| Job Matching | Suggest jobs/training | Tenant/staff choose — **no auto employment decision** |
| Tenant Assistant | Q&A for tenants | Tenant verifies critical facts with staff |

## How to use safely

1. Open the relevant dashboard panel (e.g. housing analysis, plan drafts).
2. Run agent — wait for response; check **sources / confidence** when shown.
3. Edit or reject output — document decision in normal workflow.
4. Report bad output via org process (feedback hooks in AI activity where enabled).

## What AI cannot do

- Automatically approve or reject housing applications.
- Make employment hiring decisions.
- Override RBAC or open other tenants’ records.
- Bypass organisation AI budgets or disabled features (flags per org).

## Usage caps

Organisation Admins monitor **AI costs** dashboard; excessive use may be throttled.

## Privacy

Do not paste special-category data into prompts unless DPIA allows.

## Training scenario

Present a draft support plan → trainees identify two fields they must verify manually before approval.
