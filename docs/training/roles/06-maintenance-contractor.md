# Maintenance & Contractors — training guide

**Who:** `maintenance_contractor` role.  
**Access:** Work orders and repair updates — web **Maintenance** and mobile **Work orders**.

## Assigned work

1. Sign in → **Work orders** (mobile `(tabs)/work-orders` or staff work-order detail).
2. Open job — read property/room context provided (no unrelated tenants).

## Update status

1. Set status per organisation workflow (in progress, complete, awaiting parts).
2. Add completion notes — factual only.
3. Upload **photographs** as evidence (before/after).

## Scheduling

- View schedule/visits if your org links contractor calendar to visits module.

## Approvals

- Some jobs require Organisation Admin approval before work starts — status shown on record.

## Permissions boundary

- Contractors **cannot** access caseload, support plans, or full tenant profiles unless explicitly granted (default deny).

## Mobile

- Same HMore app — contractor UI is work-order focused.
- Offline: limited; prioritise sync before marking complete.

## Security

- Do not share job photos on personal messaging apps.
- Return organisation devices or revoke session when contract ends.

## FAQs

**Q: Emergency priority?**  
A: Tenants cannot set emergency on self-service form; staff escalate.
