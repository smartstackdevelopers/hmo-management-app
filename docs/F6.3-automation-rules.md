# F6.3 Automation Rules Engine

Configurable organisation automation for reminders, escalations, and compliance sweeps. Reuses ReminderRecord delivery, complaint/compliance services, and CommunicationNotificationProvider. Does **not** auto-approve housing, change tenancy, or make employment decisions.

## Permissions

- `automation.rules.read`
- `automation.rules.manage`
- `automation.runs.read`
- `automation.escalations.manage`

## API

Prefix: `/api/v1/automation`

- `GET /dashboard`
- `GET|POST /rules`, `GET|PATCH|DELETE /rules/{id}`, `POST /rules/{id}/run`
- `GET /runs`, `POST /runs/{id}/retry`
- `GET /escalations`, `PATCH /escalations/{id}`
- `GET /compliance-issues`

## Celery

- Beat: `hmore.automation.dispatch_due_rules` every 5 minutes
- Soft time limit 240s / hard 300s
- Per-rule failure isolation; run idempotency keys; failed-run retry with max attempts
