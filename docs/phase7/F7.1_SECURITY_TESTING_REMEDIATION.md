## 1. Initial security findings (inspection summary)

| Area | Components reviewed | Initial posture |
|------|---------------------|-----------------|
| Web | `apps/web` (Next.js), Auth0 session, dashboard routes | Production OpenAPI disabled on API; CORS validated in prod settings |
| Mobile | `room-ready` (Expo), Auth0 + SecureStore | Tokens in SecureStore; offline drafts XOR + key in SecureStore |
| API | `apps/api` FastAPI, RBAC matrix, tenancy isolation, RLS helpers | Auth0 JWT RS256; org context required on tenant routes |
| AI | `apps/ai-service`, service bearer token, budgets, workflows | HMAC-safe token compare; routes 503 when token unset |
| DB | Alembic through `20261111_4500_f67`, RLS session helpers | Parameterised queries; static SQL for RLS role name only |
| Workers | Celery `redis_url` broker/backend | No HTTP surface to enqueue arbitrary tasks |
| Auth | `app/auth/deps.py`, `require_mfa`, device sessions (F4.6) | MFA enforced when `AUTH0_REQUIRE_MFA_CLAIM=true` |
| Files | F1.8 storage, type/size validation, org-scoped keys | No public object URLs in API design |
| Integrations | F6.4 Fernet + SSRF blocklist | Fixed in Phase 6 — re-tested via `test_f64_integration_hub.py` |
| Occupancy | F6.5 gate, formal deferral doc | Live ingest denied until privacy gate |
| Infra | `.github/workflows/ci.yml`, secrets-hygiene job | No committed `.env` secrets in examples |
| Phases 1–6 | Feature test modules `test_f61`…`test_f67`, isolation, RBAC | Landlord/F6.1 and finance file ID fixes present on `develop` |

**New finding (this audit):** API returned raw `TokenValidationError` / PyJWT strings in HTTP 401 bodies → information disclosure (low/medium).

**Residual (unchanged):** `AUTH0_REQUIRE_MFA_CLAIM` defaults `false` in dev; production must enable via env + Auth0 policies.
