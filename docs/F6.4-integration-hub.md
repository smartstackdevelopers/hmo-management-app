# F6.4 Integration Hub Foundation

Secure technical foundation for future Council, HR, Finance and community service API connections. Does **not** activate live partner synchronisation without verified credentials and confirmed API specifications. Connected status is set only after a real successful HTTPS connection test.

## Permissions

- `integrations.read` — organisation admin and super admin
- `integrations.manage` — organisation admin and super admin

## Provider categories

- `council`
- `hr`
- `finance`
- `community_service`

Foundation adapters: `council_generic`, `hr_generic`, `finance_generic`, `community_service_generic`.

## API

Prefix: `/api/v1/integrations`

- `GET /dashboard`
- `GET /providers`
- `GET|POST /`
- `GET|PATCH /{id}`
- `POST /{id}/test-connection`
- `GET|POST /{id}/mappings`
- `POST /{id}/sync`
- `GET /sync-jobs`, `POST /sync-jobs/{id}/cancel`
- `GET /activity`

Secret credential values are never returned in API responses.

## Security

- Fernet encryption for credentials (`INTEGRATION_SECRETS_KEY` or pepper-derived key in dev/test)
- Organisation isolation on all queries
- HTTPS required for non-local external URLs
- External responses treated as untrusted; mapping refuses protected HMore fields without authorisation

## Celery

- Beat: `hmore.integrations.dispatch_auto_sync` hourly (only integrations with `config.auto_sync` and `connection_status=connected`)
