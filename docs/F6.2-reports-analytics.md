# F6.2 Full Reports & Analytics

Extends F2.14 operational reporting with occupancy and support-plan analytics, secure stored exports, Celery scheduled delivery, and early-warning alerts. Reuses F6.1 room/tenant occupancy math. Does **not** implement F6.3 automation rules.

## Report categories

| Category | Source | Permission |
|---|---|---|
| Occupancy | properties / rooms / tenants | `reports.occupancy.view` |
| Housing applications | housing_applications + waiting_list_entries | `reports.housing.view` |
| Complaints | complaints | `reports.complaints.view` |
| Staff caseload | case_assignments / follow-ups | `reports.caseload.view` |
| Support plan completion | tenant_support_plans / goals | `reports.plans.view` |

## Exports

- Immediate stream: `GET /api/v1/reports/export/{type}/{csv|pdf|xlsx}`
- Stored artifact: `store=true` or scheduled runs → `report_exports` + `file_metadata`
- Download: `GET /api/v1/reports/exports/{id}/download` (org + allow-list / schedule manage)

## Scheduled reports

Celery beat task `hmore.reporting.dispatch_scheduled_reports` (every 5 minutes).

Tables: `scheduled_reports`, `scheduled_report_runs`.

Recipients must be active organisation members. Delivery uses `CommunicationNotificationProvider`.

## Early-warning alerts

Celery beat task `hmore.reporting.dispatch_early_warning_alerts` (hourly).

Types: overdue complaints, pending housing, overdue follow-ups, overdue plan reviews, occupancy drop, high caseload.

Duplicate prevention via org-scoped `dedupe_key` unique constraint.
